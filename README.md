React Life Cycle
=================

  There are 4 Phases
    
       - Initial Phase
            constructor()

       - Mouniting Phase
           render()
           componentDidMount()

       - Updating phase
            componentDidUpdate()
            componentDidCatch()
           
       - Umounting Phase
            componentWillUnmount()


How to achieve lifeCycle in Function Component?
===================================================
   React useEffect hooks is achieve this life cycle methods.
